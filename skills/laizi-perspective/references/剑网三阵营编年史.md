## 第一章：游戏内阵营背景设定

### 1.1 浩气盟

浩气盟成立于公元732年（开元二十年），由八大门派围攻恶人谷之后，为对抗恶人谷势力而组建的正义联盟。盟主谢渊，号"天枢"，在多次大战中凭借卓越的军事才能和人格魅力，最终成为浩气盟的实际领袖。

**八字真言**："浩气长存，天地正气"
**核心据点**：落雁城（总部）、武王城（象征性主城）
**创立背景**：少林、纯阳、天策、七秀、藏剑、神策、长歌门、霸刀八大门派联手组建

**谢渊其人**：谢渊出身天策府，军事素养极高。在浩气盟中推行严格的军事化管理，将落雁城打造成了一座固若金汤的军事要塞。旗下有七位"星宿"级首领分别掌管不同职能，八部天龙负责浩气盟的守卫。

**来源**：[剑网3官方资料站](https://jx3.xoyo.com/zl/new-zyxt.html)、[百度百科-谢渊](https://baike.baidu.com/item/谢渊)、[剑网3吧-阵营介绍](https://tieba.baidu.com/f?kw=剑网3)

### 1.2 恶人谷

恶人谷位于昆仑山外围的一处隐秘山谷，具体成立时间不详。谷中聚集了江湖中走投无路之人、被正派迫害的异类、以及真正的大奸大恶之徒。恶人谷并非纯粹的邪恶之地——世间既无绝对的善与恶，更多的不过是无奈的选择。

**谷主**：王遗风（雪魔山庄主人），身负红尘派武学传承，精通凝雪功、残尘逸流剑，手持雪凤冰王笛，位列官方设定第三级"绝"字级高手。

**核心据点**：烈风集（总部）、凛风堡（前线要塞）
**入谷口号**："一入此谷，永不受苦"
**阵营口号**："自在逍遥"

**王遗风的故事**：王遗风出身雪山派，本为翩翩公子，因挚爱"文小月"被人设计害死，悲愤之下血洗屠城，从此遁入恶人谷。他并非传统意义上的"恶人"，而是对世间正道彻底失望后的自我放逐。其人格魅力使得恶人谷成为无数无家可归之人的最后归宿。

**恶人谷十大恶人**：陶寒亭、康雪烛、莫雨、米丽古丽、肖药儿、沈眠风、柳公子、丁丁、唐书雁、烟/影（游戏不同版本有所调整）。

**来源**：[剑网3WIKI-恶人谷](https://wiki.biligame.com/jx3/恶人谷)、[百度百科-王遗风](https://baike.baidu.com/item/王遗风/9986748)、[阵营剧情讨论帖](https://tieba.baidu.com/p/9072530113)

### 1.4 阵营世界观

浩气盟与恶人谷的对立不仅仅是游戏玩法上的设定，其背后是两种价值观的深刻对立：

| 维度 | 浩气盟 | 恶人谷 |
|---|---|---|
| 核心理念 | 秩序至上，邪不胜正 | 自由至上，无拘无束 |
| 行事风格 | 堂堂正正，以多打少 | 不择手段，以弱胜强 |
| 对待弱者 | 保护弱者，维护秩序 | 弱肉强食，强者生存 |
| 代表音乐 | 《浩气长存》 | 《自在逍遥》 |
| 代表颜色 | 蓝色 | 红色 |

## 第二章：游戏版本与阵营机制演变史

### 2.1 70年代（2009-2011）：阵营系统的诞生

| 时间 | 版本/事件 | 阵营影响 |
|---|---|---|
| 2008年11月20日 | 第一次封测 | 奠定游戏基础框架 |
| 2009年4月7日 | 第二次封测 | 门派与技能体系逐步完善 |
| 2009年8月28日 | **剑网3正式公测** | 初始只有中立状态，无阵营系统。玩家之间只能通过仇杀进行PVP |
| 2010年6月3日 | "藏剑山庄"版本 | 藏剑门派加入，装备体系初具规模 |
| 2010年10月28日 | **"战魂劫"版本** | 🌟**阵营系统里程碑**：阵营系统正式上线，引入战阶系统（从1阶到14阶）、阵营攻防战（周末固定时间）、阵营日常任务。浩气盟vs恶人谷的对抗格局正式确立 |
| 2011年1月20日 | "龙争虎斗"版本 | 阵营玩法扩展到更多地图 |
| 2011年5月19日 | "巴蜀风云"版本 | 五毒门派加入，黑戈壁阵营日常上线 |
| 2011年11月17日 | "一代宗师"版本 | 轻功系统上线，阵营野外交战机动性大幅提升 |

**70年代阵营核心特点**：
- 不同阵营玩家完全无法组队、交易、一起打本
- 退出阵营后敌对NPC仍是红名，不可逆
- 阵营仇恨极深，"红名就是怪"是基本法则
- 没有成衣外观系统，玩家装备外观就是身份标识
- 拓印系统尚未开放，江湖身份靠装备说话

## 第三章：经典战役编年（深度还原）

### 3.1 蝶恋花中秋大战（2010年8月21日-27日）

**剑网三历史上影响最大、参战人数最多、报道最多的阵营战役。这场战役被视为剑三PVP的"创世纪"，直接催生了"战魂劫"版本的攻防系统。**

#### 基本信息

| 项目 | 详情 |
|---|---|
| **时间** | 2010年8月21日-27日（七天，其中激战五天五夜） |
| **服务器** | 电信一区·蝶恋花 |
| **战前格局** | 浩气强势服，人数约为恶人的3-4倍，浩气以PVE散人为主 |
| **浩气频道** | YY1213（高峰5000+在线） |
| **恶人频道** | YY60999（高峰约400在线） |
| **地图在线** | 巅峰7000+，直接导致服务器后续设置人数上限 |

#### 起因

蝶恋花是一个典型的"浩气压恶人"的服务器。浩气人数约为恶人的3-4倍，但浩气以PVE公会和散人为主，几乎没有专业PVP公会。而恶人虽然人少，却有"信念"和"天灾"两个强力PVP公会。

长期以来，恶人谷在野外PVP中处处受制于浩气盟。恶人玩家积累了大量不满情绪。2010年8月21日（农历中秋前夜），恶人谷决定发动一场报复性的突袭。

**行动策划**：此次行动由信念和天灾两个PVP公会策划，行动计划只在熟人之间传达，严格保密。行动YY在线人数约170人，实际进团推老谢的约150人。

**浩气盲点**：浩气大帮会的回防规则是"老谢报警→派人探明虚实→决定是否集体回防"。而恶人利用了这个时间差。

#### 战况实录

**8月21日（D-Day）**：
- 晚上8点前，恶人在江畔村秘密集结
- 150人精锐小队向谢渊正殿进发，路线未遇任何阻碍（浩气大部分人正在打英雄战宝副本）
- 和尚拉开NPC翟季，四名天策做T拉住谢渊
  - **主T：受折磨的灵魂**
  - **副T：残缺的记忆**
  - 这两个名字被永久写入剑网三史册
- 约4分钟，谢渊被击杀
- 从浩气报警到老谢倒下只有约2分钟（浩气回防人员跑到时老谢刚好倒下）
- 整个击杀过程浩气只有约一个团的散人回防

老谢倒下后，浩气阵营陷入震怒和羞辱。频道里刷屏："不可能！一定是BUG！"。浩气散人曾放言"老谢死，蝶服死（集体退服换服务器）"。

**8月21日晚-22日**：
- 浩气在YY1213集结，高呼"血洗恶人谷"、"打足三天三夜"、"老王不倒则集体退服"
- YY1213在线人数飙升至约5000人
- 频道内充满了各种"收号、借号、卖号"的信息
- 5173交易平台上蝶恋花账号价格不断攀升
- 浩气采用"日夜轮番战"形式，只要有指挥才能的都上麦
- 恶人谷利用有利地形顽强防守，浩气人数虽多但缺乏有效战术指挥

**8月23日**：
- 大战已经一天两夜，服务器因巨大压力崩溃
- 凌晨蝶恋花服务器重启维护
- 午间，双方都极度疲惫
- YY1213仍保持2000+在线，激情指挥+DJ舞曲不断
- YY60999则冷清得多，总人数不超过200，指挥们有一搭没一搭聊天
- 恶人开始动摇：担心浩气推不下老王真的集体退服导致蝶恋花变鬼服

**8月23日晚-24日**：
- 浩气指挥"转角遇到魔鬼"因晚上大吼被邻居举报扰民到公安局
- 指挥"夜云寒"嗓子喊破住院
- 指挥"淡淡冰蓝"的呐喊越来越"妖魔化"
- 久攻不下后浩气内部开始互相指责

**8月25日（决定性的转折——楚天登场）**：
- 楚天（非蝶恋花原住民，被大战吸引而来）22日就已在YY1213上过麦，但冷静指挥风格与"激情"氛围格格不入，被请下麦
- 经过几天对双方心理和战术的深入分析，楚天制定了一套"以牙还牙"的奇袭战略
- 他联系到浩气13个公会管理，详细分析形式和作战方针
- 各公会管理（此前被喷得焦头烂额）均同意由他统一指挥

**奇袭执行方案**：
1. 下午5:30，13个公会参战人员在秘密YY集合（YY设为隐身状态）
2. 在东昆仑集合后全部下线待命
3. 参战团以战宝团为单位编制（确保成员精英化+防内奸）
4. 晚6点，楚天到达YY1213接管指挥
5. 晚6:00-6:20，三个散人团在恶人谷入口方向佯攻吸引防守主力
6. 晚6:20，10个进攻团集体上线，清理防守力量
7. 浩气防守团到位拦截回防恶人
8. **晚6:32，老王在没有援助的情况下被击杀**

**8月25日-27日**：
- 老王倒下后，双方疲惫到达极限
- 恶人仍组织了多次反击但效果有限
- 27日，这场长达七天的战役因双方战力极度疲惫逐渐平息

#### 影响与遗产

| 影响层面 | 详情 |
|---|---|
| **游戏机制** | 直接催生了"战魂劫"版本的固定时间阵营攻防战系统（每周末定时进行） |
| **服务器限制** | 地图7000+在线促使官方后续设置地图人数上限 |
| **文化层面** | 被纸媒报道，成为中国3D网游历史上最大规模玩家自发组织的PVP活动 |
| **玩家心志** | "人歇号不停"，玩家将账号发到公屏彼此共享接替，这种为阵营牺牲的精神定义了剑三PVP的灵魂 |
| **指挥文化** | 楚天的"谋略型指挥"vs"激情型指挥"之争由此开端 |

> **"剑三再无蝶恋花"** —— 此后任何服务器都无法再现这种自发的、纯粹为了阵营荣誉而战的七天热血。这也是后来所有"阵营情怀"的起点。

### 3.2 唯满侠惊鹅之变（2016年3月6日-8日）

**一场因一只灰鹅引发的万人级61小时阵营大战。充分体现了剑三玩家"什么都可以为之一战"的江湖血性。被戏称为"鹅满侠"事件，唯满侠从此得名"鹅满侠"。**

#### 基本信息

| 项目 | 详情 |
|---|---|
| **时间** | 2016年3月6日晚-8日（61小时） |
| **服务器** | 电信五区·唯我独尊（唯满侠） |
| **规模** | 上万人参与 |
| **死亡统计** | 平均每人阵亡200次以上 |
| **修理花费** | 数亿金币（装备修理费） |

#### 真实起因（与当时流传的谣言完全不同）

**第一阶段：开局**
- 3月6日晚约6-7点，唯满侠长安城地图
- 影子帮帮主"惊鸿"正在长安城做抓灰鹅的宠物任务
- 两只恶人谷帮会因"情感问题"在附近开战
- 惊鸿莫名其妙被卷入混战并阵亡
- 鹅也没抓到，人也死了

**第二阶段：升级**
- 惊鸿咽不下这口气，一通电话叫来了大量影子帮帮众
- 对方以为影子帮是来支援的外援，也叫来更多人
- 小规模帮会战逐渐扩大

**第三阶段：谣言四起的72小时**
- 最初的谣言版本："惊鸿在抓鹅时被打"
- 演变为："影子帮带了八个团来抓鹅"
- 再演变为："一个叫'鹅'的渣男带着影子帮的帮主夫人跑了"
- 最终版本："影子帮带了八个团来抢帮主夫人"
- 谣言越传越凶，最终引爆了两个阵营的全服级别大混战

**第四阶段：全服混战**
- 参与的玩家绝大多数不知道真正原因
- "进去看到红名就打，先打就对了"
- 打到第三天凌晨，服务器因人数过载停服

**结局**：
- 官方被迫发布声明请玩家注意休息
- 第二天真相大白，玩家纷纷悔恨："我居然是为了一只鹅打了一个晚上，装备都红了！"
- 那只引发大战的灰鹅至今下落不明——有人说被路人抓走了，有人说在混战中跑了
- 官方在微博发了一张鹅的图片配上狗头表情，瞬间引爆全网围观

**后续影响**：
- "鹅满侠"成为唯满侠的永久别称
- 灰鹅被戏称为唯满侠的"阵营女神"
- 该以后代抓宠物宣布：不接唯满侠灰鹅单子——"没有八个团谁敢去抓唯满侠的鹅"
- 该以后找情缘要送鹅——"送什么玄晶披风，送鹅才能代表心意"
- 惊鸿本人表示："以后再也不抓鹅了"

### 6.3 阵营经济与老板文化

#### 打阵营的成本

打阵营是件极其烧钱的事：
- **飞机票**（帮会成员转服费用）：一个帮会转服动辄数万元
- **代练费**：帮会发放给成员的游戏币或人民币补贴
- **世界BOSS奖金**：争夺世界BOSS箱子分配的激励
- **占坑费**：在大服占一个攻防名额的灰色交易
- **指挥工资**：部分老板每月给指挥发放数万元不等的"工资"

#### 著名老板案例

| 老板 | 服务器 | 事迹 |
|---|---|---|

### 6.4 毒瘤现象全面剖析

#### A. 占坑

**定义**：派自己人加入对方阵营占据攻防名额（每场300人），减少对方有效战力。

**案例**：
- 长安浩气武王城被占坑200+（浩气实际作战人数不到150），主播直播掉城
- 电八浩气被占坑200+掉谢渊
- 唯满侠苟立国300个七秀号占满世界BOSS地图
- 大服占坑有人管（策划回应赖子/墨亦辰的诉求），小服无人问津

#### B. 内战

**定义**：同阵营帮会之间互相宣战消耗。

**月卡vs点卡的文化分歧**：
- 月卡服认为内战是正常的"抢统战"手段——合服必然有统治权争夺
- 点卡服将内战视为"毒瘤行为"——消耗同阵营资源
- 剑三官方将人员流失归咎于"内战"——但月卡玩家认为阵营输赢才是根本原因
- 赖子向策划哭诉内战→策划在本赛季和谐了内战系统（被月卡玩家痛恨）

#### C. 卡红

**定义**：不开阵营PK模式，但仍能对队友进行治疗的技巧。卡红玩家死亡不计入帮战人头统计（但奶量仍然有效），且杀人也不计算人头。

**争议**：明昼帮会在青梅使用此战术时，对手指控他们是"偷人头"，但明昼反击称"1300个人头你说是偷的？"

#### D. 游击战/收割型内战

**战术模式**：
1. 在商道/任务点集合，抓落单人员击杀
2. 对方组织反击→立即坐马车逃跑
3. 对方放松警惕→再次出现抓落单
4. 不正面硬刚，只收割弱势个体

#### E. 中立T拉守卫

白帝城案例：浩气利用中立角色T+中立奶妈拉住凛风堡守卫，使守卫失效，导致凛风堡首次被攻陷。官方未回档引发"双重标准"争议。

#### F. 三次元打击

人肉搜索、造谣诽谤、现实骚扰——跨出游戏边界的毒瘤手段。

**来源帖**：[毒瘤现象知乎](https://zhuanlan.zhihu.com/p/479953194)、[NGA 380讨论](https://ngabbs.com/read.php?tid=41428875)

### 6.5 阵营十大争议话题

1. **阵营平衡**：官方是否应该干预阵营强弱？放任自流还是宏观调控？
2. **内战合法性**：月卡服"抢统战"传统vs点卡服"毒瘤"定性
3. **占坑处理双标**：人口大服（唯满侠/双梦）占坑有人管，小服（长安/白帝城）无人问津
4. **指挥特权**：赖子/墨亦辰被认为"凌驾于玩家之上"，策划"有求必应"
5. **老板操控**：阵营被资本操控，散人玩家失去话语权——"帮会属于老板，不属于玩家"
6. **合服杀伤力**：每次合服导致阵营格局地震，部分小服玩家被"大服殖民"
7. **转阵营困境**：弱势阵营玩家想转强势被"人数平衡"拒绝，强势阵营有人数倾斜
8. **跨服雇佣兵**：月卡区玩家被雇佣到点卡区参与阵营战，改变原有生态
9. **官方双重标准**：不同服务器受到的待遇差异——"策划只为大服和明星指挥服务"
10. **阵营未来**：人口持续流失下，阵营玩法何去何从？无界化能否带来生机？

### 6.6 帮战机制与经济运营深度解析

> 以下内容整合自【剑网3魔盒（JX3BOX）】知识库文章《帮战与阵营内战》，原文发布于2021年5月19日。
> 作者为纵月玩家，对帮战玩法进行了系统性的学术化梳理。

#### 6.6.1 帮战的三大类型

文章将剑三所有帮战归纳为三个基本类型——不同的起因，但结果永远是"一方散帮/转服/咸鱼"。

| 类型 | 通俗名称 | 特征 | 纵月典型案例 |
|---|---|---|---|
| **没事找事型** | 毒瘤 | 无恩怨、无利益，纯粹恶心人。开小号建侮辱性帮会名来宣战，或莫名其妙仇杀路人 | 公主殿下、为恶 |
| **恩怨型** | 仇杀升级 | 由个人冲突→帮会间矛盾→怨怨相报，永远结不清的账 | 天禄&战鬼、千城&风月无边 |
| **利益型** | 抢地盘/抢钱 | 最复杂的一类，核心是"双方利益冲突" | 下文详列 |

**利益型帮战的细分**（原文列举了至少8种）：

| 子类型 | 说明 |
|---|---|
| 对立阵营利益 | 弱势阵营在对立阵营建"内战帮会"，专门打对方统战：跑商就打、攻防就开帮战、占坑。经典玩法 |
| 权力冲突 | 争夺据点指挥权、世界BOSS分配权。如双剑合璧合并到纵月时八大联盟vs战魂联盟 |
| 据点纠纷 | 统战不给自己帮会分配防守力量导致据点沦陷→翻脸→利益型帮战 |
| 工资分配争议 | 大攻防/世界BOSS奖励分赃不均引发的帮战——"太多了不胜列举" |
| 情缘型 | 两个男帮主争夺同一个女人→帮战。被作者称为"种间斗争" |
| 幕后老板指派 | "我与尔素无冤仇，奈何某某老板想打你，买了我这个内战帮会来揍你——本来想拒绝的，只是他给的太多了" |
| 反霸服 | 对抗"海盗"等蝗虫式霸服帮会，保护自己服务器的利益 |
| 联盟连带 | "我不想打你，但XXX是我同盟，为了保护他所以我打你" |

#### 6.6.2 帮战的武斗形式

文章将帮战的形式分为武斗和文斗两大类，以下为武斗类详解：

| 形式 | 操作方式 | 目的 |
|---|---|---|
| **收割（野外游击）** | 开帮战/加仇杀/对立阵营号，攻击对方跑商/日常玩家，刷"退帮不杀" | 逼人退帮，使对方帮会总战阶受损 |
| **大团对冲** | 团队vs团队正面对抗，地点通常在复活点、矿车岛、商道 | 以武力决胜负，胜者地图频道嘲讽宣示胜利 |
| **大跑商砸车** | 对阴山商路（大跑商）的镖头发起帮战/仇杀，用控制、刀墙、推拉等使其无法送达 | 让对方帮会损失大量战阶（1个满物资大跑商50人=15W总战功） |
| **攻防占坑** | 进图后后排划水、不承伤不奶人、关键时刻送死 | 使对方据点/阵营攻防失败 |
| **代开** | 开没人玩但有战斗力的号加入大团对冲 | 在人数上占据优势 |
| **外围（卡红）** | 非参战帮会白名奶/T加入一方团队奶人承伤——死亡不计入帮战数据 | 给一方增加有效人数，自己"死了不算" |
| **007（内鬼）** | 低端：报点/送人头；高端：渗透决策层预判对方行动 | 服务武斗，最终目标让对方散帮 |
| **仇杀恶心流** | 莫问平沙挂悬赏、明教魂锁、霸刀裁骨墙、衍天换位关人、冰心推不进本、少林拉拉扯扯等 | 利用无杀气机制——"我能恶心你但你先手打不了我" |

**收割vs大团对冲的核心区别**（原文金句）：
- 收割是**游击战**："人多打人少"、"敌进我退"，地点是"哪里有人我去哪"
- 大团对冲是**阵地战**：复活点对埋、商道正面刚，不会发生在"奇奇怪怪的山旮旯角落里"

#### 6.6.3 文斗类：不打也打

| 形式 | 操作 |
|---|---|
| 阵营频道文斗 | 刷屏嘲讽、造谣抹黑 |
| 贴吧发帖/对线 | 开帖互喷、扒黑料、编段子 |
| 人肉嘲讽 | 开盒后二次元嘲讽、QQ空间偷照片（见张巨鹿案例） |
| 集体举报禁言 | 组织大量成员举报对方指挥/帮主，使其禁言无法指挥 |
| 密聊对喷 | 一对一心理战 |

#### 6.6.4 帮战经济学的核心：帮会总战功

> 这段是全文最硬核的部分——解释了为什么收割、占坑、砸大跑商不只是"恶心人"，而是精准的经济打击。

**帮会总战功（功勋值）**是据点帮会的生命线：

| 机制 | 详情 |
|---|---|
| **据点门槛** | 每周帮会总战功必须达到140万，否则据点会持续消耗大量帮会资金，直到被系统收回 |
| **据点控制权** | 据点守卫不仅攻击对立阵营玩家，还会**攻击同阵营但对立的帮会成员**——如果你被开了帮战，你在敌对帮会的据点里连跑商都跑不了 |
| **祭天控制** | 祭天镖头由上周末阵营战功榜前三帮会派出——"我开你帮战，我送的祭天牛车你就别想在据点里混时间摸奖励" |
| **大跑商收益** | 200份物资、50人=15W总战功；100人=30W。大跑商被砸→巨额战功损失 |

**原文金句**：
> "如果镖头帮会与目的地据点所属帮会为同一战线，结合据点守卫会攻击对立帮会的机制——'如果你与我为敌，我开你帮战，我运送的祭天牛车你就别想在据点里混时间或者摸奖励'。"

#### 6.6.5 老板与霸服：阵营权力的终极形态

**老板的定义变化**（原文追溯）：

| 时代 | 老板生态 |
|---|---|
| 80-95年代（早期） | 服务器众多、小服遍布。一个有老板、有指挥、有组织的帮会能凭一己之力让阵营强势。**"彼时，作为一个强势阵营的老板是非常有成就感和话语权的。"** |
| 合服后 | 小服并入大服→原老板利益受损→"这一因素成为了利益型帮战的导火索" |
| 现代 | 老板追求的核心：话语权、统治力、阵营收益（攻防工资、世界BOSS分配） |

**霸服的五个阶段**：

> 小老板有小老板的玩法，有钱有精力又有野心的老板会搞霸服。

| 阶段 | 操作 |
|---|---|
| ①掌控帮会 | 吸收战斗力 |
| ②掌控野外 | 野外交战决定胜负 |
| ③掌控攻防、世界BOSS | 决定阵营攻防胜负的导向 |
| ④掌控据点、祭天 | 反对者无法跑商——"即使不是他们的据点也可能会通过占坑等方式丢掉再拿回来" |
| ⑤**霸服完成** | **协议攻防**：由霸服帮会决定阵营攻防胜负导向；世界BOSS分配全凭霸服帮会决定 |

**原文对"协议攻防"的定义**：
> "掌控了攻防，原本正常的玩法会沦为协议攻防，即由霸服帮会决定阵营攻防胜负的导向。"

#### 6.6.6 帮战的核心结论（原文综述）

> "剑网三目前常见的帮战，主要是由帮会恩怨或利益纠纷引起，最终伴随的往往是一方帮会的胜利以及另一方帮会的散帮、转服、咸鱼。双方互相伤害的核心目的在于：使对方帮会的总战功受到损失，或使其人员流失、口碑形象受损。"

> "剑网三帮战的结果基本不存在'平局'或'讲和'等现象，基本上都是不死不休的——毕竟这是游戏不是政治。"
